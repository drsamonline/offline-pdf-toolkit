Photos only re-encodes the JPEGs inside the file and leaves the text as text. Lossless runs qpdf over the result: it re-writes object streams and re-flates the ones that are not compressed, and changes nothing else — the text stays text and nothing is thrown away. Every page renders each page to an image: the biggest saving on a pure scan, but the text stops being selectable.

OCR not loaded

Reads text from scans. The engine is about 10 MB — two WASM cores and the English language data — and it ships beside this page, so loading it is not a download: it comes off your own disk, and your document never leaves the tab. It is only read when you press the button, which is why opening the app stays instant. Open Network above to watch that stay true.

Page size & trim
pt

Trim cuts the same margin off every edge. A page size re-lays each page onto a new sheet, scaled to fit — the text stays selectable, because nothing is rasterised.

Impose (N-up)
12

Sheets are A4 landscape. Booklet pairs the outermost pages, so the printed stack folds into reading order. Use it with a two-sided printer.

Bates numbering

The legal and medical convention: a prefix, a zero-padded counter, one stamp per page.

Split & export
150

Both act on the selected pages, or on every page when nothing is selected. Each file is downloaded separately — nothing is bundled, and nothing is sent.

Redaction

Patterns are a helper, not a guarantee — they catch those shapes in text this app can read, and see nothing inside a picture. Check the result. With rebuild on, the page is rasterised afterwards, so the text underneath is really gone; without it, a box is only a box.

Page labels

The numbers a reader sees, which need not be the numbers the file counts. A report that opens on a cover and a contents page, then starts at 1, is the usual case: the front matter is numbered i, ii and the body 1, 2, 3. This writes the label table; the printed page stays whatever you set in the header/footer tool.

    Form fields

    Fills an AcroForm and bakes the values into the page, so they cannot be edited back. A password-protected file has to be unlocked first — the Unlock panel does that.

    Signature

    Draw with a mouse or a finger, or load a picture of your signature. The ink is trimmed to what you actually drew, so a small signature stays small on the page. Remember keeps it in this browser's local storage, unencrypted — convenient on your own machine, wrong on a shared one.

    Extract images

    Recovers the pictures stored inside the PDF at their original resolution — not screenshots of the page.

    Compare

    Reads the text of the first two loaded documents page by page and reports where they differ. It compares text, not appearance — a re-scan of the same letter will look completely different and this will say so.

    Share locked

    Wraps the finished PDF in a single HTML file that asks for a PIN before it opens. AES-256-GCM with a PBKDF2-SHA256 key — the same container LockHTML writes, so a file made here opens in that viewer too, and the other way round. No server: the PIN and the document never leave this tab.

    Folder

    Runs the tools above over every PDF in a folder you pick, and writes the results to an out folder beside them. Nothing leaves your machine — the browser hands this page a folder and the page writes back into it.

    Network 0 external

    Every fetch and XMLHttpRequest this page makes is counted here, and split by whether it left this origin. Nothing should ever say external — not even the OCR engine, which ships beside the page. Your documents never appear in this list at all.
