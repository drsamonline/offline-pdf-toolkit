What it does

The jobs people normally reach for a website to do — except the file never leaves your machine.

Merge

Add several PDFs and they lay out in order. Drag any page to reorder, duplicate or delete it.

Split & extract

Select the pages you want and pull them out into a new PDF. Shift-click selects a range.

Rotate & reorder

Rotate left or right in 90° steps, move pages earlier or later, duplicate them.

Watermark

Text watermarks — centre, tiled or a corner — with size, opacity, angle and colour.

Page numbers & metadata

Number the pages in four formats and positions, and set title, author, subject and keywords.

Compress

Renders each page to an image and rebuilds the PDF — the biggest saving on scanned documents.

Images → PDF

Drop in PNGs or JPEGs and save them as a PDF, one image per page.

Password protect

Encrypt with AES-256 and set permissions — allow or block printing, copying and modifying.

Unlock a PDF

Remove a password you already know, in the browser. Nothing is sent anywhere to do it.

Extract text

Pull the text out of a digital PDF and save it as a plain .txt file.

OCR

Read text out of scans. The engine downloads once (~7 MB) and is then cached; your document is never uploaded.

Private by construction

There is no server to leak to. The whole tool is one HTML file you can keep on a USB stick.

Why it matters

Patient reports, contracts, bank statements, identity documents — the files people merge and split are usually the ones they should not be handing to a stranger's server.

Typical “free PDF tool”

  • File is uploaded to their server
  • Processed somewhere you cannot see
  • Retention policy unknown
  • Often an account, a queue, or a size limit
  • Stops working offline

Offline PDF Toolkit

  • File is read into your browser's memory
  • Processed by JavaScript on your own CPU
  • Nothing is retained — close the tab and it is gone
  • No account, no queue, no size limit but your RAM
  • Works with the network cable unplugged

Using it

Four steps, and nothing to install.

  1. Drop your files in. Several PDFs, or images, or both.
  2. Arrange the pages. Drag to reorder, select and rotate, duplicate or delete.
  3. Open the tools you need. Watermark, page numbers, metadata, compress.
  4. Save PDF. The result is built in your browser and downloaded straight to your disk.

Questions

Are my files really not uploaded?

Correct. The app is a single HTML file with the PDF engine compiled into it. There is no fetch to any server and no backend at all. You can load it, unplug the network, and it still works — which is the proof.

Does it work offline?

Yes. Save the page and open it any time. It is also installable as an app, and it registers a service worker so a second visit works without a connection.

Is there a file size limit?

No imposed limit — the practical ceiling is your device's memory. Very large scanned PDFs can be slow, especially in Compress mode, which renders every page.

What does Compress actually do?

It renders each page to a JPEG at the resolution and quality you choose, then rebuilds the PDF from those images. On a scan this can shrink a file dramatically. On a text PDF it usually makes it bigger and the text stops being selectable — so keep the original.

Can it add or remove passwords?

Yes. Password protect encrypts with AES-256 and sets permissions (printing, copying, modifying). Unlock a PDF removes a password you already know. Both happen in your browser — no file is sent anywhere.

Does OCR upload my document?

No. OCR downloads the recognition engine once (~7 MB) and caches it; after that it works offline. Only the engine is downloaded — your document is read into memory and never leaves the device.

Can I use it commercially?

Yes — see the licence. The app code is the author's; the two bundled libraries are permissively licensed (MIT and Apache-2.0).
