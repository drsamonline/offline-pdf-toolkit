Photos only re-encodes the JPEGs inside the file and leaves the text as text. Lossless runs qpdf over the result: it re-writes object streams and re-flates the ones that are not compressed, and changes nothing else — the text stays text and nothing is thrown away. Every page renders each page to an image: the biggest saving on a pure scan, but the text stops being selectable.
