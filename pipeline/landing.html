What it does

Twelve jobs that normally mean uploading a private document.

Patient reports, contracts, statements, identity papers — the files people merge and split are the ones they should least be handing to a stranger's server.

Bring it together

Add several PDFs and images, drag pages into the order you want, rotate in 90° steps, duplicate, delete, insert a blank, trim the margins, or re-lay mixed sizes onto A4 — then split the result by ranges, every N pages, or one file per page.

Mark it up

Text watermarks — centred, tiled or in a corner, with size, opacity, angle and colour — page numbers in four formats and positions, and title/author/subject/keywords.

Protect, shrink, redact

AES-256 password protection with permissions; unlocking a password you already know; compression by rasterise-and-rebuild; redaction that rebuilds the page so the covered text is gone, not just hidden.

What it refuses to do

The features that are missing on purpose.

A toolkit like this is defined as much by what it will not do. These are not gaps in the roadmap.

Upload your file

There is no server, no bucket and no fetch carrying your document. It cannot leak what it never sends.

Ask for an account

No sign-in, no email, no queue, no daily limit. Open it and work.

Edit the text inside a page

It rearranges and annotates pages. Re-flowing someone else's layout is a different, much larger program — and the wrong promise to make.

Use Ghostscript-class compression

PDF/A conversion and AGPL components (Ghostscript, PyMuPDF, CoherentPDF) would force this app to be AGPL. Compress here means rasterise-and-rebuild, which is permissive and works well on scans.

Questions

The ones people actually ask.

Are my files really not uploaded?

Correct. The app is one HTML file with the PDF engine compiled into it. There is no backend and no request carrying your document. Load it, unplug the network, and it still works — that is the proof, and you can run it yourself.

Does it work offline?

Yes. Save the page, or install it as an app: a service worker keeps the shell so a second visit needs no connection. The EXE, APK and Linux builds have no network code in the path at all.

Is there a file size limit?

None imposed — the ceiling is your device's memory. Very large scanned PDFs are slow in Compress mode, which renders every page.

What does Compress actually do?

It renders each page to a JPEG at the resolution and quality you choose, then rebuilds the PDF from those images. On a scan that can shrink a file dramatically; on a text PDF it usually makes it bigger and the text stops being selectable. Keep the original.

Can it add or remove passwords?

Yes. Password protect encrypts with AES-256 and sets permissions for printing, copying and modifying. Unlock removes a password you already know. Both happen in the tab.

Does OCR upload my document?

No. OCR downloads the recognition engine once (~7 MB) and caches it; after that it works offline. Only the engine is fetched — the document is read into memory and never leaves the device.

How do I know it is not quietly uploading something?

Three ways. The app keeps a Network panel that counts every fetch and XMLHttpRequest the page makes — open a fresh copy and it reads 0 requests. The built file has no backend address in it at all. And the self-test in the app runs merging, rotating, cropping and AES-256 encryption on your machine and reports what happened.
